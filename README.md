# La tienda de ropa de Ana
## Caso A
**Planificación, definición**. Es el momento que Ana decide qué datos se van a recolectar, cómo se van a estructurar, etc. 

## Caso B
**Captura o recopilación**. Es el punto de entrada donde se recolectan los datos directamente de la fuente, que en este es el escáner.

## Caso C
**Almacenamiento**. Ana guarda la información en un repositorio o aplicación. 

## Caso D
**Procesamiento y limpieza**. En esta fase Ana corrige los errores, y transforma los datos para que sean útiles.

## Caso E
**Análisis**. Ana calcula, a través de fórmulas cuál es la prende que deja más ganancia, y así se extraen los datos para sacar conclusiones de valor.

## Caso F
**Visualización**. Ana crea una gráfico para compartir la información.

## Caso G
**Archivo y destrucción**. Ana guarda los archivos que no se usan. Los datos que no son útiles o requeridos por ley se eliminan de forma segura.


# Rutas Eficientes S.A.
## Caso 1
**Procesamiento o limpieza**. Se limpian o filtran los errores a través de un script que detecta registros corruptos. 

## Caso 2
**Captura o recopilación**. Fase de recolección de datos por los dispositivos físicos. 

## Caso 3
**Análisis**. Se cruzan datos  y variables para descubrir patrones y optimizar las rutas/negocios.

## Caso 4
**Almacenamiento**. Las lecturas de lo sensores se guardan en la base de datos.

## Caso 5
**Archivo o destrucción**. La empresa elimina físicamente las tarjetas de memoria locales.

## Caso 6
**Visualización o compartir**. transforman los datos en un mapa visual interactivo. 

## Caso 7
**Archivo**.  Se mueven los datos que no ya se utilizan a un sitio más barato, pero que se conservan porque la ley lo exige en ciertos casos.
